# Smart Campus & Educational Portal (Університетський портал)

Наскрізний проєкт з дисципліни **«Інженерія програмного забезпечення»** (Проєктування архітектури, специфікація та стандарти інженерії).

## Інформація про виконавця
* **Студент:** Кошик Михайло
* **Група:** 2ПРс
* **Спеціальність:** 121 / F2 «Інженерія програмного забезпечення»
* **Варіант предметної області:** № 3 — Smart Campus & Educational Portal

## Опис проєкту
Інтеграційна вебплатформа для студентів, викладачів та адміністрації закладу вищої освіти, що об'єднує керування розкладом занять, електронний журнал успішності, систему подання та обробки електронних заяв і модуль онлайн-тестування.
