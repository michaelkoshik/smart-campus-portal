# 3. Сценарії атрибутів якості (Quality Attribute Scenarios)

Нижче наведено 5 деталізованих та кількісно вимірюваних сценаріїв атрибутів якості для системи **Smart Campus & Educational Portal**, розроблених на основі специфікації NFR (`docs/2_nfr_specification.md`).

---

## QAS-1: Продуктивність модульного онлайн-тестування під час пікового навантаження
* **Характеристика ISO 25010:2023:** Performance Efficiency (Capacity / Time Behaviour) — трасується до `NFR-01`, `NFR-02`.
* **Source (Джерело):** Потік із 3 000 студентів, які одночасно складають обов'язковий модульний контроль (онлайн-тестування).
* **Stimulus (Імпульс):** Надсилання клієнтськими браузерами `HTTP POST` / `PATCH` запитів на автозбереження проміжних відповідей та фінальне завершення тесту з інтенсивністю 2 500 запитів за секунду (RPS).
* **Environment (Середовище):** Пікове навантаження системи (Peak Load) під час екзаменаційної сесії або модульного тижня.
* **Artifact (Артефакт):** Reverse Proxy (API Gateway), Модуль онлайн-тестування (`Assessment Module`), кеш-сховище Redis та основна реляційна БД.
* **Response (Реакція):** API Gateway маршрутизує запити на репліки бекенду; проміжні відповіді миттєво буферизуються у Redis із подальшим асинхронним скиданням у БД, а при фінальному завершенні тесту виконується атомарний розрахунок балів та запис результату до електронного журналу.
* **Response Measure (Міра реакції):** Час відповіді клієнту **p95 ≤ 150 ms**, **p99 ≤ 300 ms**; частка помилок сервера (`5xx`) **< 0.01%**; **0%** втрачених відповідей студентів.

## QAS-2: Відмовостійкість та автоматичне відновлення під час збою контейнера
* **Характеристика ISO 25010:2023:** Reliability (Fault Tolerance & Recoverability) — трасується до `NFR-03`, `NFR-04`.
* **Source (Джерело):** Внутрішній програмний збій (витік пам'яті OOM або аварійна зупинка процесу) одного з робочих екземплярів бекенд-сервісу.
* **Stimulus (Імпульс):** Неочікуване припинення роботи Docker-контейнера `smart-campus-api-1` у момент, коли 400 студентів проходять тестування, а викладачі заповнюють електронний журнал.
* **Environment (Середовище):** Штатний робочий режим (Normal Operation) у навчальний день.
* **Artifact (Артефакт):** Контейнерний оркестратор, балансувальник навантаження (Nginx / HAProxy) та бекенд-вузли застосунку.
* **Response (Реакція):** Балансувальник навантаження за результатами health-check перевірки протягом 5 секунд виключає несправний вузол із пулу маршрутизації та перенаправляє трафік на здорові репліки; оскільки стан сесій та чернетки відповідей зберігаються у зовнішньому Redis, користувачі не втрачають авторизацію та прогрес. Оркестратор автоматично перезапускає аварійний контейнер.
* **Response Measure (Міра реакції):** Втрата збережених даних **RPO = 0**; час повного відновлення працездатності екземпляра **RTO ≤ 2 хвилин**; тривалість деградації для користувача (перемикання трафіку)
